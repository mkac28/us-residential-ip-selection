## 拿到 IP 先驗三件事：whois、ASN、黑名單

不管跟誰買，開通後花三分鐘做檢查，就能判斷拿到的是真家用寬頻，還是機房 IP 段偽裝的。

先查 whois 歸屬。真住宅 IP 常見歸屬是 AS7922（Comcast）、AS7018（AT&T）、AS6079（RCN）這類美國本土運營商；如果查出來是 AS2914（NTT）、AS3257（GTT）、AS3356（Lumen），那是 Tier-1 骨幹網路，常被小代理商包裝成「靜態住宅」出售；查到 OVH（AS16276）、M247（AS9009）、Hetzner（AS24940）就更直白——機房，共享代理的重災區。

再查黑名單，重點看有沒有 Spamhaus 之類的垃圾郵件記錄。被標記過的 IP 就算能連上，實際可用性也很差。

最後看行為特徵。偽住宅 IP 的流量更像伺服器：高併發、超長連接，有些平台會直接把它判成 hosting 或 proxy。

## 常見問題

**買美國住宅IP合法嗎？**
合法。代理是正常工具，用於隱私保護、安全和存取地區內容都沒有問題；需要留意的是目標平台的條款和當地的資料法規。

**動態 IP 和靜態 IP 到底怎麼選？**
抓資料、比價、廣告驗證用動態；帳號運營、店鋪、直播、廣告投放用靜態。判斷標準只有一條：這個環境需不需要長期不變。

**為什麼檢測網站顯示的歸屬地和我買的不一致？**
各家資料庫的來源和更新頻率不同，結果本來就會有出入。多換幾個檢測源交叉看；有爭議時可以先用 IPinfo 自查，1024Proxy 的售後就是按這個基準處理的。

**IP 被平台標記了怎麼辦？**
先確認是不是真的被標記（查黑名單、看風控表現），然後找服務商更換。能不能免費換、更換週期多長，各家差異很大，這件事要在下單前問清楚，別等出了事才問。
